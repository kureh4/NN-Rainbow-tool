VRChat / VCC / VPM

NN - Rainbow tool

lilToon対応のVRChatアバターへ、非破壊でレインボー表現を追加するツールです。VCCから導入できます。

VCCへ追加 GitHubを見る

Version

v1.0.0

Unity

2022.3 系

方式

NDMFによる非破壊統合

VCC Repository URL

https://raw.githubusercontent.com/kureh4/NN-Rainbow-tool/main/index.json

インストール

1
VCCへ追加上の「VCCへ追加」を押して、リポジトリをVCCへ登録します。
2
Manage Project対象のVRChat Avatar Projectを開き、Manage ProjectからNN - Rainbow toolを追加します。
3
Prefabを配置Packages/jp.nekoneko.nn-rainbow-tool/Prefab/NN_Rainbow.prefab を、虹色化したいオブジェクトの子へ配置します。

依存パッケージ

VRChat Avatars SDK NDMF lilToon
NN - Rainbow tool / ねこねこ
